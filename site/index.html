v2 pilot · one requisition · initial screen only

Manually sent, machine-enforced.

Ledger is Rust tooling for the audit-grade candidate feedback pilot in V2.md: 100% of rejected candidates on one high-volume requisition get a human-recorded reason, with no ATS integration and no automated decision. Every page below is generated at build time from the CLI's own output.

  • Locked form

    GATE, FIELD, ADMIN — nothing else. Named decision maker, capture timestamp, corrections supersede rather than overwrite.

  • Versioned copy

    Five gate blocks with TEXT_VERSION. A gate without documented requisition facts cannot be captured; the row must be recorded as FIELD.

  • Immutable log

    Every send stores the full body and its hash, chained to the previous line. One altered byte makes log verify refuse the file.

Run it

One sequence, copy-pasteable. Every approval below is collected from both the Hiring Manager and Legal, because a single-pass sign-off needs both. 

cargo build --release

ledger init --data pilot
ledger governance set --data pilot --escalation-owner "M. Okafor, Employee Relations"

for role in hiring-manager legal; do
  ledger gate approve      --data pilot --actor "J. Chen"   --role $role
  ledger templates approve --data pilot --actor "M. Okafor" --role $role
  ledger playbook approve  --data pilot --actor "M. Okafor" --role $role
done

ledger requisition create --data pilot --id REQ-2026-014 \
  --employer "Example Health" --title "Registered Nurse" \
  --reply-to careers-feedback@example.com.au \
  --sender-name "R. Patel" --sender-title "Recruitment Coordinator" \
  --gate right-to-work --gate work-rights-duration \
  --fact ROLE_END_OR_MIN_TERM="30 June 2027" \
  --fact MIN_TERM="12 months" \
  --fact ROLE_DURATION_REASON="The appointment is a fixed-term 12-month contract."

ledger requisition comparative --data pilot --id REQ-2026-014 \
  --attribute-1 "assessment of deteriorating patients" \
  --attribute-2 "escalation to a registrar within their first hour" \
  --attribute-3 "documentation a covering clinician could act on" \
  --evidence "a de-identified case note attached to the application" \
  --non-factors "a post-graduate qualification or a specific employer"

for role in hiring-manager legal; do
  ledger requisition approve --data pilot --id REQ-2026-014 --actor "J. Chen" --role $role
  ledger requisition approve --data pilot --id REQ-2026-014 --actor "M. Okafor" \
    --role $role --comparative
done

ledger ats import --data pilot --requisition REQ-2026-014 --file export.csv

ledger disposition record --data pilot --requisition REQ-2026-014 \
  --application APP-1001 --first-name Ada --email ada@example.com \
  --recruiter rec-rui --decision-maker dm-chen \
  --category GATE --gate right-to-work --answer not-held

ledger dispatch --data pilot --requisition REQ-2026-014 --preview
ledger qa record --data pilot --requisition REQ-2026-014 --application APP-1001 --qa qa-patel
ledger dispatch --data pilot --requisition REQ-2026-014

ledger log verify --data pilot
ledger log export --data pilot --requisition REQ-2026-014 --out send-log.csv
ledger metrics --data pilot --requisition REQ-2026-014

# Or skip the setup entirely and use the deterministic fixture:
ledger demo seed --data pilot --force

Metrics and routing

Synthetic fixture thresholds, pre-registered. The routing reads them; it does not score them.
Metric Green Amber Red
Reply volume< 30 / 1k30–80> 80
Form-block rate< 10%10–25%> 25%
Gate-mismatch rate< 2%2–10%> 10%
Criteria feasibilityyes, 1 sessionyes, external inputno
Candidate-value signal> 50% yes30–50%< 30%

The routing rule

  1. Candidate-value red → stop. Do not build v2.
  2. Gate-mismatch red → flag live discrimination exposure immediately.
  3. Form-block red → capture-discipline middleware is the v2 signal.
  4. Form-block green + criteria yes → reassess venture viability.
  5. Reply volume red → scope automated reply triage into v2.
  6. Criteria no → pivot to criteria-validation tooling.

The tool renders the exact text, applies the three circuit-breakers, and records the send. It never sends email and never calls the ATS — per the pilot's scope, dispatch stays manual.
