Implements V2.md: a locked GATE/FIELD/ADMIN disposition form with named decision makers and superseding corrections, five versioned gate blocks with requisition facts, a linted role-level paragraph, three signed-off templates, a five-scenario reply playbook, a hard initial-screen filter, second-person QA, an append-only hash-chained send log, five pre-registered metrics, and the v2 routing decision.

Usage: ledger [OPTIONS] <COMMAND>

Commands:
  init               Seed the workspace: gate copy, templates, playbook, policy
  demo               Build the deterministic synthetic fixture (no pilot data)
  status             Show the task sheet and the evidence the workspace holds
  governance         Show or set retention and the escalation owner
  gate               Inspect, approve, and version the Tier 0 gate copy
  requisition        Create, document, approve, and inspect requisitions
  templates          Inspect and approve the three master templates
  playbook           Inspect and approve the five reply scripts
  ats                Import the ATS export
  disposition        Capture, correct, and list dispositions
  qa                 Record the second-person QA check
  dispatch           Render and dispatch feedback under the circuit-breakers
  log                Verify or export the send log
  reply              Record candidate replies
  signal             Record candidate-value signals
  metrics            Compute the five metrics
  review             Record criteria feasibility and compute the v2 routing
  checklist          Sign off plan tasks
  purge              Enforce retention: tombstone expired PII
  migrate            Snapshot the workspace and migrate its schema
  anchor             Publish the chain head as an off-host receipt
  find               Resolve a redacted #hash handle back to its record
  operator           Register and inspect operator identities
  verify-signatures  Re-check every disposition's operator signature
  help               Print this message or the help of the given subcommand(s)

Options:
      --data <DIR>
          Pilot workspace directory
          
          [default: ledger-data]

      --debug-ids
          Reveal raw application ids and emails in console output (they are redacted to stable #hash handles by default)

      --operator <NAME>
          The operator acting. Defaults to LEDGER_OPERATOR, then the only registered operator

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version
